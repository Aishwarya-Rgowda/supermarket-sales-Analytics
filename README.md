# Supermarket Sales Analytics Dashboard

## 📌 Project Overview
This project is an interactive Supermarket Sales Analytics Dashboard developed using Python and Streamlit.

It helps analyze supermarket sales data through tables, charts, and interactive visualizations.

## 🛠️ Technologies Used
- Python
- Pandas
- Streamlit
- Plotly
- MongoDB

## ✨ Features
- Sales data analysis
- Product-wise analysis
- Category-wise analysis
- Date-wise analysis
- Interactive charts
- Data visualization

## 📂 Project Files
- `app.py` – Main Streamlit application
- `supermarket_sales.csv` – Sales dataset
- `import_data.py` – Data import script
- `import_mongodb.py` – MongoDB connection/import script
- `requirements.txt` – Required Python libraries
